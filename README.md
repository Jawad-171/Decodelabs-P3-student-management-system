# Student Management System

A simple and professional Student Management System built with PHP and MySQL.

This project demonstrates database integration, CRUD operations, form validation, prepared statements, search functionality, and responsive UI design.

## Features

- Add new students
- View all students
- Edit student information
- Delete student records
- Search students by name, email, phone, or course
- Form validation
- Prepared SQL statements
- MySQL database integration
- Responsive design
- Clean and professional interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- WAMP
- VS Code
